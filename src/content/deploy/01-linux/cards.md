## 常用命令与目录

### 是什么
后端上线后天天要打交道的是 Linux：目录（`/etc` 配置、`/var/log` 日志、`/opt` 或 `/home` 放应用）、文件查看（`cat` / `less` / `tail -f` / `grep`）、检索（`find` / `ps` / `ss`）。

### 怎么用
排查三板斧：`tail -f app.log` 看实时日志，`grep -n "ERROR" app.log` 找错误，`ss -lntp | grep 8080` 看端口监听。改配置前先 `cp nginx.conf nginx.conf.bak`。

### 常见坑
- `rm -rf` 在生产目录没有撤销键，路径一定先 `pwd` 确认。
- `tail -f` 对按天切割的日志会「跟丢」，轮转后用 `tail -F`。
- 用 root 跑应用方便但风险高，应建专用账号并限制目录权限。

### 面试怎么问
「服务起不来你怎么查？」答端口、进程、日志、权限、依赖资源五步，能说出具体命令更好。

## 权限、进程与端口

### 是什么
`rwx` 对应读/写/执行，`chmod 755 file` 表示属主可读写执行、其他人可读执行；`chown` 改属主。进程用 `ps -ef` / `top` 查看，端口用 `ss -lntp` 或 `lsof -i:8080` 查看。

### 怎么用
应用账号只需对应用目录与日志目录有写权限，配置目录给只读。启动失败先看 `Permission denied` 与端口 `Address already in use` 两类报错。

### 常见坑
- 文件有执行权限不等于能运行，还要看解释器、依赖库与 SELinux/AppArmor。
- 端口没起来不等于应用没启动，可能绑定在 127.0.0.1 而非 0.0.0.0。
- 防火墙/安全组没放行时，本机 curl 通、外网不通，别只查应用。

### 面试怎么问
「755 是什么意思？」答三组 rwx 的八进制表示，顺便说最小权限原则。

## 动手清单
1. 用 ls -l 查看一个文件权限，改成 600 再改回 644，观察属主与其他人的访问差异。
2. 起一个监听 8080 的进程，用 ss -lntp 找到 PID 并用 kill 结束；自测标准：能说清端口与进程的对应关系。
