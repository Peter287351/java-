## 镜像与容器

### 是什么
镜像是分层、只读的模板（含代码、运行时、依赖）；容器是镜像加一层可写层跑起来的进程。一个镜像可以起多个互不共享可写层的容器。

### 怎么用
`docker pull nginx:1.25` 拉镜像，`docker images` 查看，`docker run -d --name web -p 8080:80 nginx` 起容器，`docker ps -a` 看全部容器，`docker logs -f web` 看日志，`docker exec -it web sh` 进去排查。

### 常见坑
- `docker rm` 会丢掉容器可写层里的数据，重要数据必须挂卷。
- 容器里进程退出，容器就退出；Java 应用要以前台进程运行，别在启动脚本里后台化。
- `docker stop` 发 SIGTERM，默认 10 秒后 SIGKILL，优雅停机时间不够要调 `--stop-timeout`。

### 面试怎么问
「镜像和容器的关系？」答类与实例、只读模板与可写运行实例，顺带说出分层复用。

## run 的常用参数

### 是什么
`-d` 后台运行、`-p 宿主端口:容器端口` 映射端口、`-v 宿主目录:容器目录` 挂数据卷、`-e KEY=value` 注入环境变量、`--name` 命名、`--restart unless-stopped` 定义重启策略。

### 怎么用
Spring Boot 容器常用：`docker run -d -p 8080:8080 -e SPRING_PROFILES_ACTIVE=prod -v /opt/logs:/app/logs --name app myapp:1.0`。配置不要打进镜像，用环境变量或挂载配置。

### 常见坑
- `-p 8080:8080` 左边是宿主机端口，写反会连不上。
- 容器内部访问宿主机不能用 127.0.0.1（那是容器自己），要用宿主机网关或 host 网络。
- 环境变量里放明文密码会留在 `docker inspect` 里，敏感值应走密钥管理。

### 面试怎么问
「容器删了数据还在吗？」答容器可写层随容器删除，只有挂了 volume 的数据才保留。

## 动手清单
1. 用同一个 nginx 镜像起两个不同端口的容器，验证彼此互不影响。
2. 起一个不带卷的容器写文件，删除容器后重新创建并观察文件是否还在；再挂一次卷对比。
